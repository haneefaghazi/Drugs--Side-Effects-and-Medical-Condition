# 😊 Drugs, Side Effects, and Medical Conditions

This project leverages a comprehensive database to provide detailed information about various drugs, their side effects, and the medical conditions they treat. It helps healthcare professionals and patients gain better insights into medications' uses and potential side effects.

## 📊 Project Overview

Understanding drugs, their side effects, and their medical applications is crucial for informed healthcare decisions. This project compiles a detailed dataset on various medications, allowing users to explore side effects, treatments, and drug interactions.

## 🧰 Tools & Technologies

- Python (Pandas, NumPy, Matplotlib)
- SQLite3 (for database management)
- Flask (for potential web interface)
- Jupyter Notebook (for exploratory data analysis)
- Tkinter (for GUI interface)

## 🔄 Workflow

### 1. Data Collection & Structuring
- Compiled data on drugs, their side effects, and medical conditions from multiple sources
- Cleaned and normalized the dataset for consistency

### 2. Data Exploration & Analysis
- Analyzed relationships between drug types and medical conditions
- Investigated common side effects associated with specific drug classes

### 3. Database Development
- Created a relational database to store information on drugs, side effects, and conditions
- Designed efficient queries for retrieving data based on user input

### 4. Interface Development
- Developed a command-line interface (CLI) for interacting with the database
- Built a basic GUI using Tkinter to allow users to search and explore the data more easily

## 📈 Results

- Developed a robust database for storing drug-related information, side effects, and treatments
- Users can search for drugs by name and view their side effects and medical uses
- Insights on drug safety and effectiveness can be easily accessed for healthcare professionals and patients

## 🧠 Insights

- Certain drug classes are more prone to side effects, such as gastrointestinal issues or allergic reactions.
- Exploring drug side effects and medical uses together can lead to better treatment choices.
- A well-structured database can streamline medication decision-making for both doctors and patients.
